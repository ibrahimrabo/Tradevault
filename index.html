FAQ

Questions, answered.

Is TradeVault free?

Yes. The launch version is intended to be free. Optional premium features may be introduced later.

Do I need a broker connection?

No. You can manually journal trades. Broker and prop-firm integrations are part of the longer-term roadmap.

Can I use it on my phone?

Yes. The interface is designed responsively for phones, tablets and desktop browsers.

Is my trading data public?

No. The planned cloud architecture uses user authentication and row-level security so users access their own records.

Will you add payments?

Yes, when premium features are ready. Payment providers will be integrated through secure checkout flows rather than storing card details in TradeVault.

Does TradeVault tell me what trade to take?

No. It is a journaling, analytics and learning tool, not personalized investment advice.
