# TradeVault — Trading Journal

Open `index.html` in a modern browser.

Features:
- Dashboard with Net P&L, win rate, profit factor and average R
- Equity curve
- Trade logging modal
- Trade history with search/filter/delete
- Setup breakdown
- Pre-trade checklist
- Daily journal
- Analytics for direction, best/worst trades and wins/losses
- Data persists in browser localStorage

This is a front-end prototype; no server/database is required.
